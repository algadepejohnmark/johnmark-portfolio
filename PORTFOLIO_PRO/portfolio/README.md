# Personal Portfolio Website

Static site: HTML, CSS, JavaScript. No build step, no dependencies.

## Run locally
- VS Code: open this folder, install the "Live Server" extension, right-click index.html > Open with Live Server.
- PyCharm: open this folder, open index.html, click a browser icon in the top-right of the editor.
- Terminal: `python -m http.server 8000` then visit http://localhost:8000

## Structure
index.html, about.html, skills.html, projects.html, resume.html, contact.html
css/style.css | js/main.js | images/

## Deploy (GitHub Pages)
1. Create a GitHub repo and upload all files (index.html at the root).
2. Settings > Pages > Deploy from branch > main / root.
3. Your live URL appears after a minute.

## To customize
Search every .html file for "Your Name", "Your School", and placeholder text.
Replace images in images/ (same filenames, or update the src paths).
